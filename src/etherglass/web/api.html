OFFLINE INSTRUMENT / API REFERENCE

Recording in.
Evidence out.

The observatory, Python API, and command line share the same analysis path. This local HTTP interface is intended for loopback use on your own machine. It does not need an external account or a hosted service.

Endpoints

REQUESTBEHAVIOR
GET /api/healthReturn the instrument version and offline replay status.
GET /api/demoGenerate the fixed-seed reference recording and return its calculated plots, provenance, occupancy, and classification.
POST /api/importImport a recording as multipart form data. Send data_file and optional meta_file, sample_rate, center_frequency, and datatype.
POST /api/analyzeInspect a selected interval or reconstruct the target with explicit priors. Send JSON using the example below.
GET /api/export/{capture_id}Download a ZIP containing a SigMF recording and analysis report. The component query is mixture, target, or residual. Reconstruct before requesting an estimated component.

Analyze a recording

{
  "capture_id": "ID returned by import or demo",
  "start_sample": 0,
  "stop_sample": 4096,
  "target_center": 0,
  "symbol_rate": 125000,
  "method": "hybrid",
  "inspect_only": false
}

start_sample is inclusive and stop_sample is exclusive. Both refer to the original recording, even after inspecting a crop. Set inspect_only to true to refresh plots without separating. target_center is a baseband offset in Hz from the RF center. symbol_rate is in baud. Available methods are hybrid, matched, wiener, and unet.

Sample encoding & metadata

Samples are interleaved I,Q pairs. Supported encodings include cf32_le, cf32_be, ci16_le, ci16_be, ci8, and cu8. Integer samples are converted to floating point before analysis. A raw file requires explicit sample rate and RF center frequency. A center of 0 identifies a baseband capture.

A SigMF metadata file carries the sample rate, datatype, tuning information, license and provenance. Conflicting explicit fields are rejected instead of silently replacing the file's metadata. A selection must stay inside a single tuning segment.

What the plots establish

Every spectrum, waterfall, I/Q trace, region estimate and sample cloud is calculated from the loaded samples. Occupied regions are heuristic energy detections and do not establish a transmitter count. The I/Q geometry view is an unsynchronized sample cloud, not decoded symbols.

The learned separator assumes a supported pulse-shaped PSK target with the stated center and symbol rate. Its residual contains interference, noise and reconstruction error. A single-sensor mixture of arbitrary cochannel sources can be ambiguous. A model estimate does not establish recovery of the transmitted waveform.

Confidence and unknown status reflect the classifier's supported families and calibration domain. They do not certify that every unfamiliar waveform will be rejected. Quantitative separation metrics require clean reference signals; user recordings do not acquire ground-truth metrics merely by being analyzed.

Keep the evidence

Exports preserve provenance, metadata, the chosen analysis interval, method diagnostics and limitations alongside the complex samples. Record the original source's license and your authority to analyze or redistribute it. This instrument does not transmit RF signals or decode private messages.
