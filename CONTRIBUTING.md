# Contributing

Start with the CPU setup in [QUICKSTART](docs/QUICKSTART.md), then run `pytest`.
Keep numerical and domain claims tied to reproducible evidence. A useful change
includes a concrete failure, an observable correction, and a proportionate check.

The initial model targets one known-rate, root-raised-cosine BPSK/QPSK component
under sparse narrowband interference. Extending that domain requires new disjoint
training/calibration/test recordings, fair matched-prior baselines, and a revised
model card. Do not relabel source domains as modulation classes.

Recordings must have explicit analysis and redistribution rights. Preserve
source/session/device boundaries before windowing. Never add private recordings,
credentials, decoded messages, transmit functionality, or fabricated chart data.

The original code is MIT, original synthetic data CC0, and third-party bytes keep
their own license. Submit source alongside changed figures or videos. A local
test pass does not establish a published or scientific outcome.
